# 🛰️ CyberVayuNexus: Rogue Drone Detection System



A real-time system designed to detect, track, and alert against unauthorized drone activity along sensitive borders, enhancing national security through advanced aerial monitoring.



---



\## ✨ Key Features



\* \*\*Real-Time Detection:\*\* Utilizes computer vision and sensor data to identify drones in real-time.

\* \*\*Trajectory Tracking:\*\* Maps and predicts the flight path of detected drones.

\* \*\*Alert System:\*\* Automatically sends alerts to security personnel when a rogue drone is detected.

\* \*\*Data Logging:\*\* Keeps a detailed log of all drone activity, including timestamps, flight paths, and drone types.

\* \*\*Dashboard Interface:\*\* \[Optional] A user-friendly dashboard to visualize drone activity on a map.

\## 🚀 Getting Started



Follow these instructions to get a copy of the project up and running on your local machine.



\### Prerequisites



\* Python 3.8+

\* pip (Python package installer)



\### Installation



1\.  \*\*Clone the repository:\*\*

&nbsp;   ```sh

&nbsp;   git clone \[https://github.com/manan3251/CyberVayuNexus.git](https://github.com/manan3251/CyberVayuNexus.git)

&nbsp;   ```

2\.  \*\*Navigate to the project directory:\*\*

&nbsp;   ```sh

&nbsp;   cd CyberVayuNexus

&nbsp;   ```

3\.  \*\*Create and activate a virtual environment:\*\*

&nbsp;   ```sh

&nbsp;   # For Windows

&nbsp;   python -m venv venv

&nbsp;   .\\venv\\Scripts\\activate



&nbsp;   # For macOS/Linux

&nbsp;   python3 -m venv venv

&nbsp;   source venv/bin/activate

&nbsp;   ```

4\.  \*\*Install the required dependencies:\*\*

&nbsp;   ```sh

&nbsp;   pip install -r requirements.txt

&nbsp;   ```

&nbsp;   \*(Note: You will need to create a `requirements.txt` file by running `pip freeze > requirements.txt`)\*
